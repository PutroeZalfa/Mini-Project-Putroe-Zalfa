# Mini-Project-Putroe-Zalfa
Nama : Putroe Zalfa
NPM : 250810701100024

**Fitur:**

* Input data mahasiswa secara interaktif (nama, NIM, nilai).
* Menyimpan data menggunakan array objek (`Mahasiswa[]`).
* Pengecekan status kelulusan otomatis (nilai minimal 60 dianggap lulus).
* Menampilkan rekapitulasi data secara rapi di terminal.

**Komponen yang Dipakai:**

* Bahasa Java.
* `java.util.Scanner` untuk membaca input dari keyboard.
* Konsep OOP dasar: Class & Object, Array of Objects, perulangan `for`, dan percabangan `if-else`.

**Struktur File:**
Simpan dalam satu folder dengan nama file `Main.java` (di dalamnya sudah termasuk class `Mahasiswa` dan class `Main`).

**Cara Menjalankan:**

1. Buka terminal/command prompt di folder tempat file disimpan.
2. Ketik perintah untuk kompilasi:
`javac Main.java`
3. Ketik perintah untuk menjalankan program:
`java Main`
4. Ikuti instruksi input data di layar sampai selesai.
